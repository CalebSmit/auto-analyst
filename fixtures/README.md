# fixtures/

**What belongs here.** Golden fixtures per skill and per scope, plus one adversarial fixture per guard - built specifically to defeat the guard it targets.

**What does not.** No client data, ever. Fixtures are masked, synthetic, or public.
Public means a document a regulator publishes - see `public/`, which carries the source
and date of each one. Nothing a client sent this firm belongs here in any form.
