## Intent

Point a button at a .docx once, press it when that data is ready, and have it replace one appendix and nothing else. It shows what it will change before it writes, and it writes a new copy rather than editing last year's report in place - because the thing being edited is the only copy of last year's work until somebody has checked this one.

- [x] Set up a report: last year's file, and a source document per appendix

- [x] A dry run that says what would change, before anything is written

- [x] Three buttons on /admin, and the routes behind them

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Updating one appendix leaves the others byte-identical
- The report it read is not modified; the result is a new file
- A preview reports the same change the write makes, and writes nothing
- There is no path from any button to appendix G, H or I
- report/ is reached by something a person can press, and its allowlist entries are gone
