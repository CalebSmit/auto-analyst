# P125 - The formulas a workbook gets wrong

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** The reviewer's reads  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-10-01

## Intent

Find the formulas in a workbook that are quietly wrong - a total short of its block, a total counting a total, a plug in a row of formulas, a copy that landed a row off - and put the findings where a run records them and a person reads them, without ever gating a release on them.

## Tasks

- [x] tools/formula_audit.py: eight checks in three severities over openpyxl, reporting only
- [x] tests/workbooks.py: generated workbooks holding one of each defect, and a clean one
- [x] the footing check reports what it could not evaluate rather than passing
- [x] ReleaseGate records release.audited for every workbook it releases, after the ledger
- [x] a console route and a Check formulas button, re-derived from the released bytes
- [x] fix the P82 scan listing tools/ twice now that it has an __init__.py

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Each of the eight checks fires on a workbook built to contain its defect, and none fires on a workbook built to be correct
- A workbook with a wrong formula is still released; the findings are a record, never a refusal
- The footing check names how many totals it could not evaluate, so silence is never read as a pass
- The audit is reachable three ways - a released run, the console, the command line - and a test holds each
