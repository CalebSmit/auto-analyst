## Intent

An eighth port, chosen the way the other seven are. The port takes a document and returns the text on each page, so the adapter owns rendering and the reader needs no new dependency; OCR produces lines, and the existing table recovery turns lines into rows, so every provenance locator downstream works unchanged. A figure read by OCR is less certain than one lifted from a text layer and has to say so, because the acceptance rule now turns on evidence. And the whole point is that no model is in this path: masking happens after the text exists, so an adapter that reached one would invert the order the guarantee rests on.

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A scanned page read through the port produces lines, and the table recovery finds its rows with the locators it would have had from a text layer
- An OCR-derived line is distinguishable from one lifted out of a text layer
- Nothing under ports/ocr imports ports/llm, and the import walk fails if it ever does
- Absence is not a pass: with no OCR adapter configured a scanned page stays reported, exactly as before
- The OCR adapters are checked against the protocol by the same conformance suite as the other seven ports
- serve.py --check names the OCR seam, green when an engine is configured and honest about what is lost when it is not
