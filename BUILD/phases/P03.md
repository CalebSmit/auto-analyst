# P03 - Ports and adapters, with one conformance suite

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

## Intent

Six interfaces and their local adapters, plus a single suite every adapter must pass. This is what makes adding ShareFile later a class rather than a refactor.

## Blueprint nodes this phase implements

`storage_port` `delivery_port` `secrets_port` `queue_port` `llm_port` `compute_target` 

## Tasks

- [x] Six Protocols under ports/, each with the narrowest surface that works
- [x] storage: local_folder adapter. delivery: local_folder adapter
- [x] secrets: dotenv adapter, reading presence never printing value
- [x] queue: in_process adapter
- [x] llm: a fake adapter that replays recorded fixtures, so phases 4-10 need no API key
- [x] One conformance suite, parameterised over every registered adapter
- [x] An import-boundary test: nothing outside ports/ imports an adapter directly
- [x] ports/compute: a Protocol and a local_process adapter, so the run manifest can record where the work happened

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- All six ports have a Protocol and at least one adapter
- The conformance suite passes for every registered adapter
- No module outside ports/ imports a concrete adapter
- Switching AA_STORAGE_ADAPTER changes behaviour with no pipeline code touched
