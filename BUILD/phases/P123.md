## Intent

One command that reports a run as it goes - the step, the elapsed time against the bound the plan set, the spend against the ceiling, what is waiting on a person and what has gone quiet - so the first real run can be watched rather than guessed at.

- [x] It reports the current step and how long it has been running
- [x] It reports spend so far against whichever ceiling binds first
- [x] It says what is waiting on a person and what the stall detector has raised
- [x] It reads the record and changes nothing
