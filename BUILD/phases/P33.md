# P33 - Registered recipes

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block H - Practice groups and their workflows  
**Gate.** `auto` - closes on green tests alone.

## Intent

Which workflows may run on client work is a recorded decision with a name on it, the same as which skills may.

## Blueprint nodes this phase implements

`skill_board` `skill_registry` `run_plan` 

## Tasks

- [ ] A recipe registry: name, version, digest, approver - written only by the board
- [ ] load_recipe refuses an unregistered recipe outside the test suite
- [ ] The board's decision surface covers recipes as well as skills

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- An unregistered recipe cannot run on client work
- A recipe edited after registration loses it, because the digest changes
- Registration names the person who approved it, and refuses without one
