# P27 - The governance chain

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block G - Scale, judgment and handoff  
**Gate.** `auto` - closes on green tests alone.

## Intent

Skills are how this system changes, and ungoverned change is the main long-term risk. A dropped draft is a candidate, not a skill.

## Blueprint nodes this phase implements

`skill_drop` `skill_conformance` `skill_adapt` `skill_sandbox` `sandbox_test` `skill_submit` `skill_board` `shadow_run` `skill_registry` `governance_log` 

## Tasks

- [ ] Drop folder, conformance check against the skill contract, adaptation bench
- [ ] Authoring sandbox and its test harness, reading masked payloads only
- [ ] Submit, review board, shadow deployment with a sustained agreement threshold
- [ ] The registry as the single writer to the live skills/ tree
- [ ] The governance record

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- No path from the drop folder to the tree skips fixtures, review or a shadow run - remove any one gate and the path breaks
- Governance reads only masked payloads and registries, never client-identifying data
- Nothing reaches the skill index without passing fixtures and a shadow run
- Promotion requires a sustained agreement threshold, not one good day

## Verify

```
python -m uv run pytest tests/p27 -q
python tools/gate.py check P27
```

## Note

The adaptation bench can produce a conforming skill. It cannot produce fixtures - those are evidence the skill works, and evidence cannot be authored by the thing it vouches for.
