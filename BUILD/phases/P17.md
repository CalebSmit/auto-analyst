# P17 - Readers and the Source Parse Store

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block D - First real vertical, local end to end  
**Gate.** `auto` - closes on green tests alone.

## Intent

Turn files into an addressable parse that provenance and tie-out can read from - the store finding F2 showed nothing owned.

## Blueprint nodes this phase implements

`doc_reader` `workbook_reader` `doc_classifier` `period_detector` `untrusted_boundary` `source_parse` 

## Tasks

- [ ] pypdf and python-docx extraction, attaching source_id and a page/table/row locator to every emitted item
- [ ] Workbook reader: structural read of names and headers, one model call selects sheets with reasons, deterministic code normalizes only those
- [ ] Document classifier and the period/scale detector, with an explicit ambiguous flag rather than an assumption
- [ ] The untrusted content boundary
- [ ] The Source Parse Store keyed (run_id, source_id, locator), written once by the readers and never updated, plus its locator resolver

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every extracted figure resolves by (source_id, locator) through one interface, whatever kind of file it came from
- Every skipped sheet is reported with a reason
- A PDF carrying instructions in 1pt white text and zero-width characters reaches a model as data, not as instructions
- Scale ambiguity is reported and never assumed - thousands versus units is the most expensive silent error available here
