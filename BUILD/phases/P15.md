# P15 - Confidence router, review queue, decision log

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block C - The harness around one step  
**Gate.** `auto` - closes on green tests alone.

## Intent

Decides what a person sees, item by item, and makes their answer the only thing in the system that can write a precedent.

## Blueprint nodes this phase implements

`confidence_router` `checkpoint_policy` `review_queue` `review_surface` `decision_log` 

## Tasks

- [ ] Materiality thresholds and the auto-accept confidence bar, both per engagement
- [ ] Checkpoint policy that may only tighten, never loosen a skill's floor
- [ ] Review queue with an SLA and a named owner per engagement
- [ ] Review surface API and the decision log
- [ ] Optimistic locking so two reviewers cannot silently overwrite each other

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A policy attempting to lower a skill's review floor is rejected
- A material item is queued regardless of confidence
- The second reviewer on an item sees the first's decision rather than overwriting it
- A recorded decision re-enqueues the waiting run at its frontier
