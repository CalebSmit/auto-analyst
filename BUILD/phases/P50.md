# P50 - The map, made correct

## Intent

A view that lies when the network drops, loses your selection when you pan slowly, and closes when you clear a search is not one that can be made to look expensive. This phase is the defect list from five reviews: the geometry the drawing is built on, the pointer and keyboard handling, and the states that a person has explicitly asked for and is not given.

## Tasks

- [x] Measure the drag threshold from pointerdown, not from the previous pointermove, so a slow pan keeps the selection
- [x] Escape in the find box clears the box; only Escape outside it closes the view
- [x] Restore focus to a control that still exists, since refresh() replaces the button the map was opened from every five seconds
- [x] Say so when a run's record cannot be read, instead of drawing it as a run that touched nothing
- [x] Keep LAST_TRACE's identity, so the map cannot paint one run's colours under another's title
- [x] A step onto a name the blueprint has no node for must not dim the whole canvas
- [x] Hiding a state hides its nodes and their edges, takes them out of the tab order and out of the pointer, and beats the focus dimming
- [x] Give focus its own ring, distinct from selection, and bring a focused node into view
- [x] Stop .near overwriting the run state of up to nineteen nodes at once
- [x] Guard the shortcuts with modifiers, let ctrl+wheel zoom the page, and scale the wheel by its delta
- [x] Coalesce the address-bar rewrite so a held key cannot exhaust the browser's replaceState budget
- [x] Recompute the view on resize and on crossing the side panel's breakpoint
- [x] Fix the node box to one height in the map's stylesheet, and measure a built node before computing an edge, so the drawing has one source for it

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A slow pan does not clear the selection; a fast one still does not pick a node
- A failed trace or events fetch is reported, and the 'Nothing ran' statement is never made from a network error
- Hidden states are hidden: not focusable, not clickable, not stepped onto, and their edges go with them
- Every node keeps the colour of what the run did there, whatever else is marked on it
- The node box is exactly the height the edge maths draws to, measured rather than asserted, so the stylesheet and the geometry cannot disagree again
