## Intent

Restate figures to the scale the template declares, once, in the one place that already knows both numbers and can record what it did - leaving the writer arithmetic-free so the lock around it still means what it says.

## Tasks

- [x] Figures are restated to the template's declared scale before the mapping resolves them
- [x] A ratio that is not an exact power of ten is refused rather than approximated
- [x] The builder stays arithmetic-free, and a test fails if a multiplication appears in it
- [x] One event carries every restatement, naming each figure, both scales and the value before and after

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A figure at the scale the client sent reaches a thousands template with its value restated and the restatement on the record
- A figure already at the template's scale is untouched and nothing is recorded about it
- The writer still refuses a mismatch, because nothing downstream may rely on it restating
- The Numeric Integrity Lock still brackets a write it can prove faithful
