# P97 - A name a scanner ran into the next word

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Reading what a client actually sends  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-22

## Intent

Make the masker and the Outbound Payload Scan find a declared identifier whose internal spacing the page did not preserve, and keep the two matching by one shared rule rather than two that look alike. The fix belongs above the OCR adapter because it must hold for whichever engine is installed - fixing rapidocr would leave tesseract and the next one to be found separately.

## Tasks

- [x] One matching rule, shared: whitespace inside a declared identifier matches whatever the page put there, including nothing
- [x] The scan uses that same rule, so a masker that misses and a scan that passes cannot come apart
- [x] Hold the direction of the error: looser matching may mask more than needed and may never mask less
- [x] Say what is not covered - a scanner that drops a letter rather than a space is a different problem and this does not solve it

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A declared identifier is masked whether or not the page kept the spaces inside it
- The scan catches the same identifier the masker would have missed, and a test proves it against a stubbed masker that does nothing
- Masking still never touches a figure, a period label or an account number it should leave alone
- The masker and the scan derive their matching from one function, and a test fails if either grows its own
