# P96 - The documents a valuation engagement really receives

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Reading what a client actually sends  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-21

## Intent

Raise the match rate on a real folder by reading what is there - the folder a file sits in, the words in its name, and the document types a non-ESOP valuation is actually sent - without inventing a match where there is none. A wrong match is worse than an unmatched file, because an unmatched file is on a list somebody reads.

## Tasks

- [x] Fix the confidence bug: Classification exposes 'confidence', not 'score', and a getattr default hid it
- [x] Carry the folder path into Evidence, and give it its own weight - a client who filed a document under 'Board Minutes' has told us what it is
- [x] Add the document classes a non-ESOP valuation engagement receives, drawn from the real folder rather than from imagination
- [x] Hold the line on false positives: a name cue alone stays tentative, and a tie is still 'other'

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every confidence the tracker reports is the classifier's own, and a test fails if it is read off a missing attribute again
- A file's folder is evidence, and a folder name alone can classify
- The thirteen files of the real client folder classify as recorded in tests, with no invented match
- No file classifies as something it is not: the false-positive cases are named and held
