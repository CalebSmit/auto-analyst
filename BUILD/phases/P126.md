## Intent

Read a .docx or a Markdown document for the marks of machine-written prose, the mechanical slips, and the terms a document spells two ways - and be quiet on a document that is fine, because a check whose findings are mostly not findings teaches a reader to skip the section it is in.

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every check fires on prose written to contain its defect, and the module describes each one
- A Markdown document built out of code fences, tables, CLI flags, file paths and fiscal years produces no slips at all
- A well-written paragraph produces nothing, and the defined-term check is silent on an ordinary word that sometimes starts a line
- --fix makes four substitutions, leaves a fenced block and a table byte-identical, refuses a .docx, and refuses to write without being told where
- A tell alone is a zero exit and a slip is not, so nobody's commit fails over an em dash
