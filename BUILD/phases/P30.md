# P30 - Registered methodology: cleared once, checked every run

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block H - Practice groups and their workflows  
**Gate.** `auto` - closes on green tests alone.

## Intent

Methodology is evidence-free reference material that reaches every call, so it is cleared by a person before it can, and checked by a hash after.

## Blueprint nodes this phase implements

`context_builder` `skill_registry` 

## Tasks

- [ ] A methodology registry: digest, who cleared it, when - written only on a clearance
- [ ] Clearance scans with the conformance patterns and the untrusted boundary
- [ ] The Context Builder refuses to attach a file whose digest is not cleared
- [ ] Preflight reports uncleared or edited methodology at setup

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A methodology file carrying something shaped like client data cannot be cleared
- An edited file loses its clearance automatically, because the digest changes
- The Context Builder refuses an uncleared file, and the refusal names it
- The run-time check is a hash lookup, so it cannot fail on a false positive
