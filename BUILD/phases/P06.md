# P06 - Graph compiler

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block B - The engine  
**Gate.** `auto` - closes on green tests alone.

## Intent

Turn a named job recipe into a typed DAG with a plan hash. Nothing executes that has not been through here.

## Blueprint nodes this phase implements

`graph_compiler` `run_plan` `job_recipes` 

## Tasks

- [ ] The frozen Step dataclass: id, kind, skill, inputs, output_schema, timeout_s, retries, loop, on_failure, max_turns
- [ ] Named job recipes in YAML, compiled to a DAG
- [ ] Topological ordering and parallel-branch identification
- [ ] Declared loop regions with an integer ceiling; undeclared cycles rejected
- [ ] plan_hash over structure, skill versions, model pins, template version, taxonomy version, schema versions and the precedent-store snapshot id

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- An undeclared cycle is rejected at compile time with a locatable error
- Identical inputs and configuration give an identical plan_hash
- Changing the precedent-store snapshot changes the plan_hash
- max_turns defaults to 1, and a step declaring more is rejected

```
python -m uv run pytest tests/p06 -q
```

Recipes, not a model, produce the plan until P26. Debugging plan compilation and a model's plan proposal at the same time means trusting neither.
