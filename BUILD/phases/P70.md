# P70 - The gate can always say why

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** The consoles  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-18

## Intent

A check's output belongs to whatever the check ran - pytest, ruff, uv - and may contain any character. The console it is printed to on Windows is cp1252 and cannot encode most of them. gate.py holds the string safely and then loses it at the print, which turns a reportable failure into a traceback about encodings. P58 made this tool's independence from the project environment a tested property for the same reason: it is the tool the others are checked with.

## Tasks

- [x] Printing a check's output cannot raise, whatever the console can encode
- [x] What cannot be encoded is replaced rather than dropped, so the rest of the line survives

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A check whose output contains a character the console cannot encode is still reported, and the gate still refuses
- The replacement is visible in the line rather than the line being lost
