## Intent

From any run, a person can open the design of record at full size, see which of its 118 nodes that run went through and what happened in each, and read a difference between the system and its blueprint rather than have it hidden.

## Tasks

- [x] The blueprint's own geometry exported beside its graph - node positions, bands and column labels - and covered by the same digest, so the console draws the design of record rather than a second layout of it
- [x] A full-screen map from the run detail and from a #map= link: every node placed where the blueprint places it, edges drawn, each node bordered by what this run did there
- [x] Pan, zoom, fit, a view that opens on the part the run went through, ids legible when zoomed out, and the keyboard for all of it
- [x] A node says what happened in it: its state, what the blueprint says it is for, and every event this run recorded against it
- [x] A name a run records that the design has no node for is named as a difference, not dropped

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every node of the blueprint is drawn, at the position the blueprint gives it
- A node's border is the state the run's trace recorded for it, and a node the run never reached is drawn as never reached
- What a run recorded against a node is readable from the node
- A node the run names and the blueprint does not have is reported on the map rather than discarded
