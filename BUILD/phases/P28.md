## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- No managed-service primitive is depended on anywhere in the codebase
- HANDOFF.md names every environment difference between this machine and the work one
- A clean clone plus .env reaches a passing suite with no undocumented step
- The image builds and the whole suite passes inside it with no host Python involved, using any OCI-compatible runtime - podman, containerd, Rancher Desktop or Docker Engine. No step depends on Docker Desktop, and HANDOFF.md names the runtime actually used
- A change that moves a public surface fails a test naming it, and accepting it is a recorded decision
