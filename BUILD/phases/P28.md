# P28 - Docker, portability, handoff packet

**Block.** Block G - Scale, judgment and handoff  
**Gate.** `human` - tests passing is necessary but not sufficient; a human signs off.

## Intent

One image, any host. The portability requirement in its most concrete form - and the packet that makes the move to the work machine boring.

## Blueprint nodes this phase implements

`compute_target` 

## Tasks

- [ ] Dockerfile and compose: app plus Postgres, one command up
- [ ] The whole suite green inside the container
- [ ] HANDOFF.md: what changes on the work machine and what does not
- [ ] Adapter stubs named for the existing ShareFile and Box connectors, with their port contracts written
- [ ] The work Anthropic key as a .env change and nothing else

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- docker compose up then pytest is green with no host Python involved
- No managed-service primitive is depended on anywhere in the codebase
- HANDOFF.md names every environment difference between this machine and the work one
- A clean clone plus .env reaches a passing suite with no undocumented step

## What needs a person

You clone the repo onto the work machine, run the suite in the container, and confirm nothing but .env had to change.

    python tools/gate.py close P28 --signoff "name: what you checked"

## Verify

```
python -m pytest tests/p28 -q
python tools/gate.py check P28
```

## Note

The three work repos - model builder, ShareFile connector, Box connector - are named here as adapters to write, not as dependencies to satisfy.

```
python tools/gate.py checkpoint C10
```
