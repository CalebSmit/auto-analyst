## Intent

Intake classifies a file to a document type from its name and content. That answers what kind of file it is, and not which thing that was asked for it answers - a different axis, and the one the analyst tracks. The folder a file arrives in already carries that answer, and the firm's own numbering (B.6, C.7, D.5) is used as a key on the tabs of the tracker. Building the stable half now means the per-engagement item lists can be dropped in from the analyst's real examples without reshaping anything.
