# P91 - A report is a document with named places in it

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Closed.** 2026-09-21

## Intent

Find the place an appendix belongs by name, and move a body of Word content into it with the things that make Word content render - styles, numbering, images - carried with it. Copying paragraphs alone produces a document that opens without complaint and is laid out wrong, which is the failure nobody notices until it has been sent. Whatever cannot be carried is named rather than dropped.

## Tasks

- [x] An appendix registry: id, title, the anchor it binds to, the source it takes. Data, not code
- [x] Find anchors in a .docx by bookmark and by heading, and refuse by name when one is missing
- [x] Move a body of content between documents with styles, numbering and images intact
- [x] Report what could not be carried instead of dropping it

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- An appendix binds by bookmark or heading name, and a paragraph index cannot be used as an anchor
- An anchor that is not in the document is a refusal naming it, never a best guess
- Content that carries a style the destination does not define arrives with that style defined
- A numbered list and an image survive the move
- Anything that could not be carried is named in the result
- The two reachability scans derive their package list from the tree, and a package cannot vouch for its own submodules
