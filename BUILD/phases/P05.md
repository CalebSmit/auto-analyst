## Intent

Five-layer resolution, deeper shadows shallower, overlays may only tighten. This is what makes 'an engagement can only see the skills its scope resolves to' true by construction rather than by policy.

## Blueprint nodes this phase implements

`scope_resolver` `skill_tree` `skill_index` `scope_registry`

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- An overlay that lowers a HITL requirement or widens a privacy class raises
- Consulting resolves to the firm layer only, and the resolver says so explicitly
- The skill index never contains a skill body or a reference file
- Every scope combination the declared taxonomy admits - eight today, including the one no engagement uses yet - resolves to exactly one skill set, with no skill in it twice
