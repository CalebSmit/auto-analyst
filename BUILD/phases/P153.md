# P153 - A file that is not text is not text

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Extraction  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-10-02

## Intent

Stop a binary file being decoded as text and passed on as content, read the one format in that group that genuinely is text, and give every other file an answer that says what it is and what to do about it.

## Tasks

- [x] a file whose bytes are not text is refused rather than decoded, with what it looks like in the diagnostic
- [x] an RTF is read with striprtf, so the words survive and the control words do not
- [x] the formats that route nowhere are given an answer, and the routing table says which are read
- [x] Record INTAKE.FORMAT_NOT_READ in BUILD/surfaces.json

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- No file that is not text reaches the parse store or a model as text, proved on the formats that were doing it
- An RTF is read as the words a person reads, with the markup left behind
- A file this build cannot read is refused with a diagnostic that names the format and the thing to do, rather than with a decoding artefact
