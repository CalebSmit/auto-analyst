# P45 - Safe to leave open

## Intent

The console can be left open on a working machine: nothing a client's file carries can run in it, nothing but this machine can drive it, and when something breaks it says so instead of looking idle.

## Tasks

- [x] esc() escapes the quote characters, ids reach handlers through data attributes rather than generated inline script, and every id in a URL is encoded
- [x] Identity middleware travels with the ops routes; the Host is checked; a cross-origin request is refused; the model door's scan covers everything the adapter sends
- [x] uvicorn is given proxy_headers=False, so the peer address cannot be rewritten by a header
- [x] A failed load says so and keeps what it had: no empty state stands in for a server that cannot be reached, and no panel is left shimmering
- [x] One modal helper in the theme: scoped ids, one dialog at a time, a submit that cannot be double-sent, Escape, focus in and back out, and its listener removed
- [x] Rows are reachable by keyboard, the toast is announced, and the layout has a breakpoint below which it scrolls in one column

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- No page builds a script handler out of data, and esc() escapes every character that could close one
- A request with a foreign Host or Origin is refused, and the ops routes carry the identity check on their own
- When a load fails the page says so, and no empty state or skeleton stands in for it
- A dialog opened over another does not take the first one's fields, and a decision cannot be sent twice
