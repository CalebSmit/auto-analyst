## Intent

Make accuracy measurable rather than asserted, over more than one document. A tool that reads a filing, reads the filer's XBRL, and reports two directions: a figure the reader produced that the filer never reported, and the date each column's figures actually belong to. Plus the documents to run it on - a second real PDF from a different filer, and a workbook the regulator generated rather than one openpyxl wrote.

## Tasks

- [x] A tool that compares what the readers extract against the filer's XBRL facts, by date and by value
- [x] Say which of the three answers each figure got: tagged at this column's date, tagged at another, tagged nowhere
- [x] Add a second ARS PDF from a different filer, with its provenance recorded
- [x] Add EDGAR's own Financial_Report.xlsx, which is a workbook of real statements laid out by nobody here
- [x] Be honest about what the comparison cannot see: companyfacts serves dimensionless facts, so a figure tagged only against a segment is absent from it and is not a reader error

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- The tool reports, for the filing already in fixtures, that every figure matches a fact at its own column's date
- It runs on a second filer's PDF and on the regulator's workbook, and says what it found on each
- A figure the reader gets wrong is reported, proved by giving the tool a figure that is wrong
