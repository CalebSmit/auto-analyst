# P173 - Every box, every target, every name

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Reading what a client actually sends  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-10-07

## Intent

Nothing on any page is clipped, shattered or pushed out of its panel; nothing a person reads is below the floor the sheet states; every control is big enough to hit; every length and every colour in the product is a named token, including the ones the sheet itself had been choosing by eye; an empty panel reads as composed rather than unfinished; and a stopped run says why once, in a sentence, rather than three times in three vocabularies. Proved by sweeping the served pages rather than by reading them.

## Tasks

- [x] A row holding a sentence wraps it: the sheet stops forcing nowrap on every sub, the nine pages that were overriding it by hand use a component, and the preflight check list takes the same shape as the findings above it
- [x] Nothing a person reads is under the floor: the design's node names come off the ink reserved for placeholders and disabled controls, and a sweep over every text node on every page holds it
- [x] Every control clears the 24px a target needs, from one token, because a target is an ergonomic constant and not a typographic one
- [x] Every type size in the product is a named step: the scale gains the sizes the sheet had been choosing by eye, and nothing is left as a bare length
- [x] An empty panel is composed - a mark, a title and the next action - rather than a sentence adrift in white
- [x] A stopped run says why once: the diagnostic leads with what happened, the duplicate state line goes, and a row carries one pill the way the sheet says

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- No element on any served page is clipped horizontally without an ellipsis, and nothing lies outside the panel that paints it
- Every text node on every page clears 4.5:1, or 3:1 where it is large, measured against what is actually painted behind it
- Every control that is not an inline link is at least 24px in its smaller dimension at the smallest root the fluid scale reaches
- No font-size anywhere in the product is a bare length except the one fluid root, and every colour is a token
