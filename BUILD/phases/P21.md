# P21 - Model builder, template registry, release

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block E - Real skills and their surfaces  
**Gate.** `auto` - closes on green tests alone.

## Intent

openpyxl into a copy of a pinned template, bound by named range and never by cell address. One node releases client work, with one inbound edge.

## Blueprint nodes this phase implements

`sk_model` `t_registry` `t_template` `model_builder` `deliverable_qc` `release_gate` `idempotency_ledger` `delivery_port` `local_out` `workpaper` 

## Tasks

- [ ] Template registration: introspect the workbook, list its declared named ranges, assert every required mapping input is present
- [ ] The CONFIG.TEMPLATE_INPUTS_MISSING diagnostic with code, owner and what_now
- [ ] Model-load emitting a mapping; the Template Writer performing every write
- [ ] Deliverable QC: opens, resolves, stamped, no residual tokens, no broken external link, no #REF!
- [ ] The single release gate and the idempotency ledger record inside the release transaction
- [ ] Workpaper narrative, written after the numbers are locked, with no schema field a figure can enter through

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A binding to a cell address is rejected at registration
- A template declaring 41 of 43 required inputs fails registration naming the two missing ranges
- A produced .xlsx opens with no #REF!, no broken link and no residual mask token
- A replayed release does not deliver a second time
