## Intent

Put the column in the locator rather than more values in the row. A table with three columns writes three blocks - p12/t1/c1, c2, c3 - each with one value per row, each aligned to a period end the detector already found. Row keeps its shape, so provenance, tie-out and the numeric lock are untouched, and footing gets more correct rather than less: a total is re-added against its own column instead of a mixture. The escalation narrows to what is actually ambiguous - rows that disagree about how many figures they carry, or columns that cannot be matched to periods - rather than firing on every comparative document. And because the columns are known, what the model is shown can be a table instead of a flattened line, which is what the extraction literature attributes its accuracy to.
