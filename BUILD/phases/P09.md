# P09 - Context builder

**Block.** Block B - The engine  
**Gate.** `auto` - closes on green tests alone.

## Intent

Everything a model is shown is assembled in one place and recorded, so any call can be reconstructed exactly.

## Blueprint nodes this phase implements

`context_builder` 

## Tasks

- [ ] Assemble skill body, declared references, firm standards, retrieved precedents, engagement_profile and the masked payload
- [ ] Content-hash the assembled whole into context_ref
- [ ] Persist the assembled context against the run
- [ ] Progressive disclosure: reference files loaded only once a skill is selected

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- context_ref reproduces the exact bytes a model was shown
- Changing a retrieved precedent changes context_ref and therefore step_key
- A skill body is never loaded for a skill the plan did not select
- Precedent retrieval is scope-built and cannot cross an engagement boundary

## Verify

```
python -m pytest tests/p09 -q
python tools/gate.py check P09
```

## Note

context_ref in the idempotency key was a correction: without it a resumed run could return a cached result the current context would no longer produce.
