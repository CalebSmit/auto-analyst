## Intent

Let a person settle, once per engagement, the scale the client's statements arrived in - so a run stops asking a question answering cannot resolve. The same shape as the currency settlement beside it: a stated cue always wins, a declaration fills a silence, nothing is defaulted, and the substitution is an event rather than a quiet edit.

## Tasks

- [x] The engagement profile may declare the scale the client's statements arrive in
- [x] A source with no scale cue takes it, emitting the same kind of record the currency settlement does
- [x] A source that stated its own scale keeps it, and a profile never overrides a cue
- [x] With nothing declared, the escalation stands - a scale is settled by a person or not at all
- [x] The new profile field lives at a new contract version, and 1.0.0 stays exactly as it was

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A run whose statements state no scale proceeds once the profile declares one, and the record says where it came from
- A source carrying its own scale cue is untouched by the declaration
- No declaration means the run still stops, and the reason still names the file
