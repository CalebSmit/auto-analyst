# P104 - Which documents a skill is even asked about

## Intent

Stop sending a skill documents of a kind it cannot read. Which types carry a period and a scale is a fact about the vocabulary, so the Contract Registry declares it and the input builder asks - rather than a list in the harness that goes stale the first time a type is added and nobody remembers.

## Tasks

- [x] The registry declares, per intake document type, whether it carries figures over periods
- [x] The input builder gives the timing and tagging skills only the sources of a type that does
- [x] A run whose every source is of a kind that carries nothing says so, rather than handing a skill an empty list
- [x] A new document type has to declare this, so the answer cannot be forgotten into a default

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- The real client folder's twelve bound files reach a run and only the financial ones reach timing
- A document type added without declaring whether it carries periods is refused by the registry
- A board minute in the folder no longer produces a review item nobody can answer
