# P172 - The white space, the reason, and the word you do not know

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Gate.** `auto` - closes on green tests alone.

## Intent

A person can read the board without reading white space, find out why a run stopped without leaving the run, look up a word they do not know, and see whether a figure is moving. Every panel on every board is bounded by something this build decides, and panels that share a band share a height - which is what makes a set of boxes read as one designed thing. Nothing concludes; every colour is a token and every length is on the two scales; every motion still stops under the one reduced-motion rule.

## Tasks

- [x] The run-detail panel is bounded: its decisions are one summary line and a disclosure, and the panel is a stream, so the board has a maximum height whatever a run decided
- [x] The sentence that says why a run stopped is drawn on the run, out of the diagnostics the payload already carries, not only on the whole-design map
- [x] The Setup and Activity boards are laid out in bands, so panels sharing a band share a height, the way the Analytics board already does
- [x] The glossary has a find box, and a word that matches nothing says so
- [x] An engagement's watched folder is made when the engagement is made, so there is somewhere to drag files before anything is dropped through the page
- [x] The / key goes to a page's find box on every surface that has one, written once in the shared shell, because the whole-design view has answered it since P49 and the consoles answered nothing

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- No panel on any board is more than 1.6x the height of the tallest panel sharing its band, measured from the stylesheet and the markup
- Every board panel is still bounded by something this build decides, and the panel bound is still one number in one place
- A quarantined run's own diagnostic is rendered on the run detail, and a run with none renders nothing extra
- Every colour added is a token the theme defines and every length is rem or a token; every animation added stops under the one reduced-motion rule
