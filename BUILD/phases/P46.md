## Intent

The tool looks like something a valuation firm paid for: one spacing scale, one type scale, ink that is legible at every weight, and emphasis spent only where meaning is.

## Tasks

- [x] Tokens for spacing, type, elevation and easing, and every value in the stylesheet taken from them
- [x] Ink set as literal values measured against the paper: body 12:1, secondary 7:1, quiet at the 4.5:1 floor - and the quiet grey is no longer used for anything a person has to read
- [x] Emphasis where the meaning is: untouched nodes of the map lose their chips, a diagnostic is a rule rather than a wash, the figure carries more weight than its label, and pills are quiet
- [x] The masthead, the cards, the dialogs and the controls given real hierarchy - display type that carries a page, titles that read as titles, and one focus ring for the whole tool
- [x] An engagement row that a long client name does not break, and no page-level type sizes in pixels outside the fluid scale

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every ink token meets its stated contrast against the surface it is read on, computed rather than asserted
- No page defines a colour or a type size of its own; both come from the tokens
- The keyboard has a visible focus ring, and motion respects a reduced-motion preference
