## Intent

Six questions get asked in front of a stopped run: where did it stop, why, what had it done, what would have happened next, what do I do now, and is the work so far usable. The view answers two and a half. This phase is the other three and a half, in the words the people who ask them use.

## Tasks

- [x] The header names the run and says what happened to it, against a denominator that means something
- [x] Draw the path the run actually took, and mark the hops the blueprint has no edge for rather than implying flow that did not happen
- [x] Separate a node this run was blocked from reaching from one no run has ever used
- [x] Open on the stop, with a button that goes back to it
- [x] The side panel's first screen: the verdict, one sentence on where it stopped, what it got through, what it did not, the time and the cost
- [x] Say what to do now, and carry the button that does it
- [x] Go through every visible string and use the words an analyst and an MD use
- [x] How long each step took, from the events already in hand
- [x] A link to send, and the keys, visible rather than only in a tooltip

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A person who has never seen the tool can say, from the first screen and without clicking, which run this is and what happened to it
- The nodes this run was blocked from reaching are distinguishable from the ones nothing ever uses
- No accent-coloured edge asserts a flow the run did not take
- Every string on the screen is one of the words the glossary or the analyst uses, and a test holds the list
