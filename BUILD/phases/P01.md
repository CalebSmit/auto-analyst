# P01 - Project structure and build-state system

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block A - Foundations (the walking skeleton)  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-02

## Intent

Create the shape the whole project lives in, and the state system that lets any session - here, or Cursor on the work machine - know where the build is without reading a conversation. No domain logic at all.

## Tasks

- [x] Repo tree matching the blueprint's own repo listing, every directory with an __init__.py and a README saying what belongs there and what does not
- [x] uv toolchain: pyproject.toml, Python 3.12 pinned, uv.lock committed
- [x] ruff + pytest + mypy configured in pyproject, no separate config files
- [x] BUILD/: plan.json as truth, PLAN.md and STATE.md generated, LEDGER.md and AMENDMENTS.md append-only
- [x] tools/gate.py: status, check, close, checkpoint, amend, ledger, render
- [x] CLAUDE.md at the repo root carrying the session rules
- [x] tests/p01 asserting the structure is what the blueprint says it is

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every directory in the blueprint repo tree exists and carries a README
- uv sync reproduces the environment from a clean checkout
- gate status prints the cursor with no arguments
- gate close P02 refuses, because P02 has not been built
- The gate tests derive their targets from plan.json rather than naming a phase, so they stay true as phases close
- The blueprint is authoritative in the repo, and sync_blueprint.py publishes to the mirror rather than pulling from it
- BUILD/phases/PNN.md are generated by gate render from plan.json, not maintained by hand
- Each package names the phase that first builds it, and the ahead-of-plan check binds only packages whose phase has not been reached

## Verify

```
python -m uv sync --frozen
python -m uv run ruff check .
python -m uv run pytest tests/p01 -q
python tools/gate.py render
python tools/gate.py check P01
```

## Note

The refusal test matters more than it looks. A check-off mechanism that cannot refuse is decoration.
