# P51 - The map, drawn like a drawing

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** The consoles  
**Gate.** `auto` - closes on green tests alone.

## Intent

Make it a drawing of a system rather than a diagram of a data structure: one state family, lines with direction and grammar, a sheet with a ground and a frame, type on the scale, and an opening view at a size its own marks survive.

## Tasks

- [x] One state recipe - a wash, a hairline and a mark - so the five read as a family and hover is the same for all of them
- [x] Arrowheads, and the blueprint's line grammar by the edge kinds that are actually in the data
- [x] The stage becomes a ground and the canvas a sheet, framed, with the dead gradient removed
- [x] The band rules fade, the privacy boundary is drawn as a boundary, and column labels stop borrowing the band label's type
- [x] The step badge joins the state family and adopts the console's own mark
- [x] Every size in the map's stylesheet comes off the type scale and every colour off a token
- [x] The legend is a plate on the drawing whose swatches are the nodes' own treatment, not a second copy of it
- [x] Rank the tool bar so it does not wrap at 1280, and stop the exit being the loudest thing on screen
- [x] Open at a zoom the state marks survive, and glide between steps rather than teleporting

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- The map opens above its far-zoom threshold, so the border that carries state is never drawn sub-pixel on first sight
- Every edge says which way it goes, and guard, loop and masked edges are distinguishable from flow
- A test runs the design system's own two rules - no colour of its own, no size off the scale - over the map's stylesheet, which until now it could not see
- The legend's swatches are generated from the same rules as the nodes, so the key cannot drift from the drawing
