# P83 - A context that says when it will not fit

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** The consoles  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-20

## Intent

Two halves, because one without the other still misleads. Proactive: the context builder measures what it assembled against a ceiling declared in constraints.yaml beside the methodology one, and refuses naming the section that is too big - which is the client's document, by name, not a byte count nobody can act on. Reactive: a refusal that still comes back from the provider is diagnosed by what it says rather than assumed to be a missing model, because a ceiling set here cannot know every provider's limit and the one that is wrong is the one that matters.

## Tasks

- [x] The assembled context is measured against a declared ceiling before it is sent
- [x] The refusal names which section is too big, and what a person does about it
- [x] A provider refusal about length is not reported as a missing model
- [x] The ceiling is a decision in constraints.yaml, beside the methodology ceiling that already exists
- [x] The surface snapshot and the blueprint's ERRCODES table both name the new code

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- An oversized context is refused before the call, naming the largest section and its size
- The diagnostic tells a person which document to look at, not a number in bytes alone
- A provider 400 about length carries a length diagnostic, and a real missing model still carries the model one
- Nothing that fits today is refused
