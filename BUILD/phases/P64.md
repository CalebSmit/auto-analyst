# P64 - An acknowledgement that says what it looked at

## Intent

interview.py scan refuses an empty register unless a person has recorded that they looked and found nobody. That acknowledgement expires when a later session is logged - by date, with same-day counting as covered, because the legitimate flow is to finish a session and then record it. The consequence is that any session run after an acknowledgement on the same day inherits it. Recording which session logs were reviewed distinguishes the two orderings; a date never can.

## Tasks

- [x] The acknowledgement records the sessions it was made over, not only its date
- [x] A session logged after the acknowledgement does not inherit it, whatever day it falls on
- [x] An acknowledgement written before this change is read conservatively rather than trusted

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A session recorded after an acknowledgement on the same day does not inherit it, and scan refuses
- The legitimate flow still works: finishing a session and then recording that nobody was named leaves scan clean
- An acknowledgement with no recorded session list covers only sessions strictly before its date
