# P174 - The first thing a new machine says

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Reading what a client actually sends  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-10-07

## Intent

The first thing a new machine prints reads like the rest of the report - what it means for the person, then the command, then the code - and the runbook tells the truth about what the machine will say and about where to find the check it names. Both rehearsals are run to the end against a clone's own server on today's code, which is the only way the gitignored files a developer's machine accumulates cannot hide a clone-only failure.

## Tasks

- [x] A vault that will not open is reported as the setup step it is, in the report's own voice, with its sentences on their own lines and its code kept for quoting
- [x] The runbook names the check a reader is looking for rather than a position in a list, and says that the first command prints the vault line and why
- [x] A test holds the runbook's claims about preflight to the registry, so a check that is renamed or reordered cannot leave the runbook pointing at nothing
- [x] Both rehearsals run to the end against a fresh clone's own server, on the code this is being handed over at

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- No sentence in the runbook names a preflight check by a position that the registry does not agree with
- The vault failure prints the diagnostic's own sentence rather than an exception class name, and its code on a line of its own
- A fresh clone reaches a served console and both rehearsals report no findings against it
