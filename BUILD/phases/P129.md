# P129 - Reading the firm's model, and refusing to say what its names mean

## Intent

Turn the work-machine handoff from a design exercise into an hour of reading: one command against the real model writes the named-range inventory and a draft input schema in the registry's own shape, with every line it proposed marked so the draft cannot be registered unread.

## Tasks

- [x] tools/read_template.py: the inventory, and a draft in TemplateInputs.load's shape
- [x] an input is an empty single cell under a name this build did not reserve
- [x] every proposed line carries a REVIEW marker; the draft does not load until they are gone
- [x] scale defaults to 1, not to the firm's thousands convention
- [x] a name it cannot follow is reported, never dropped

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- The inventory resolves every defined name - global and sheet-local - to a sheet, a cell and whether it is empty, a number, a formula or a block
- A draft a person has read loads into TemplateInputs, and one they have not does not
- A name pointing at a missing sheet, two destinations or a whole column is reported rather than dropped
- The whole path works against a workbook this tool was not written against, and every name it proposes is a name that workbook really has
- It never writes into the workbook, and never over a draft somebody has been through
