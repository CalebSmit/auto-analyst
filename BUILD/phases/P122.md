# P122 - A call the plan can bound, and no loop the graph does not own

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** A run that finishes  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-24

## Intent

Make the timeout the plan already computes the one that bounds the call, and make the executor's declared retries the only retries - so a slow provider produces a bounded, visible failure instead of an unbounded silence.

## Tasks

- [x] The step's timeout reaches the provider and bounds the call
- [x] The transport retries nothing; the executor's declared count is the whole retry policy
- [x] A call that runs out of time is a transport failure, retried by the graph and recorded
- [x] The bound is on the record, so a slow step can be seen while it is happening

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A step that declares 300 seconds cannot spend longer than that in one call
- One step makes at most as many provider calls as the plan says it may
- A timeout is distinguishable from a refusal, in the event and in the code
