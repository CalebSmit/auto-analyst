# P23 - Ops console, scorecard, drift, stalls

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block F - Assurance and operations  
**Gate.** `auto` - closes on green tests alone.

## Intent

Every run ends with a computed verdict against versioned criteria, so no run's outcome is a matter of opinion.

## Blueprint nodes this phase implements

`ops_console` `run_scorecard` `analytics` `drift_monitor` `stall_alert` `cost_meter` 

## Tasks

- [ ] FastAPI plus SSE over the event bus
- [ ] The run scorecard: coverage, provenance, tie-out, conflicts, masking, numeric integrity, budget, review outstanding, deliverable QC
- [ ] Versioned acceptance criteria, so 'what counted as working' is answerable for a run six months old
- [ ] Drift monitor over override rate, confidence distribution and guard failure rate
- [ ] Stall detection against the review SLA

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every run gets a scorecard with a computed verdict
- The console replays a completed run from the event stream alone
- A stalled review item raises an alert against its SLA
- Node state comes from explicit events, never inferred from a log line's severity
