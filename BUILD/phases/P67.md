## Intent

The confidence router decides what reaches a person. For a judgement a skill proposed, a confidence score is a reasonable gate. For a figure read out of a client document it is the wrong one: the failure that matters is a misread the model is confident about, and the thing that catches it is arithmetic that does not foot. The analyst will not re-check a figure that carries its page and row and whose totals re-add; he wants to see every figure that no arithmetic covers.

## Blueprint nodes this phase implements

`B-037` 

## Tasks

- [x] An extracted figure with no source locator goes to a person, whatever its confidence
- [x] An extracted figure no arithmetic covers goes to a person, whatever its confidence
- [x] An extracted figure with both may be accepted unseen, and the confidence bar does not also have to be met
- [x] Evidence substitutes for the score and never for a review requirement somebody raised

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A figure carrying its locator and a passing arithmetic cover is accepted without a person, with no confidence stated
- A figure missing either one goes to review, and the reason names which is missing
- Materiality, an always-review category, review_required and a raised review level still send a fully covered figure to a person
- A skill's judgement, which is not an extracted figure, is routed exactly as it was before
