# P04 - Event bus, run store, manifest

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Block A - Foundations (the walking skeleton)  
**Gate.** `auto` - closes on green tests alone.

## Intent

The record. Every guard writes to it, passes included, so silence is never ambiguous - and the manifest is written unconditionally, including when a run halts.

## Blueprint nodes this phase implements

`event_bus` `run_store` `run_manifest` `checkpoint_store` 

## Tasks

- [ ] SQLAlchemy models: run, step, event, artifact, review_item, decision
- [ ] A repository port over the store, so SQLite and Postgres are one URL apart
- [ ] Append-only event bus - no update path exists in the API at all
- [ ] Manifest writer wired to run end regardless of outcome
- [ ] The seven run states: queued, running, waiting, quarantined, halted, delivered, superseded

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A halted run still writes a complete manifest
- The event table has no update path reachable from application code
- All seven run states are reachable and asserted in tests
- The same suite passes against Postgres in Docker, not only SQLite
