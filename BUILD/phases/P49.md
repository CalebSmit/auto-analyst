## Intent

A person can walk a run through the design in the order it happened, see what any node is joined to, find a node by name, and do all of it from the keyboard.

## Tasks

- [x] The order the run went in: a numbered badge on each node it touched, the side list in that order with times, and step controls that walk it
- [x] Picking a node draws the edges it is on and rings what it is joined to, and the panel lists what feeds it and what it feeds as links
- [x] A find box over name, id and practice group, and a legend whose swatches show and hide by what happened
- [x] The keyboard: one stop per node the run touched, a state in every label, a focus trap, focus given back on close, and the picked node announced
- [x] A link to one node of one run, and a click on the paper to go back to the whole of it

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- The order a run went through the design is on the map and in the list
- Picking a node shows what it is joined to, and lets a person walk to it
- A node can be found by name, and the states can be shown and hidden
- The map can be worked entirely from the keyboard, and says what is selected
