## Intent

One double-click starts the tool on a new machine, and everything an analyst does - add files, adjust an engagement, take the deliverable, find out what a word means - is on the page, with nothing silently ignored.

## Tasks

- [x] start.cmd and tools/start.ps1: find uv, install if stale, create .env, generate the vault key, ask once for the API key without showing it, make the folders, check, start, open the browser - changing nothing already set
- [x] serve.py reads .env into the environment on start (the shell wins, blanks skipped, AA_NO_ENV_FILE opts out); one parser shared with the secrets adapter; the rehearsal opts out
- [x] Setup: a files panel per engagement (full path with copy, what is there, drag-and-drop upload into the watched folder only, recorded with digest); settings (budget, review level, quiet period); watch and destination dialogs from the checklist; methodology read before it is cleared
- [x] Activity: a released run lists its deliverables with a download checked against the release digest; an empty page says how a run starts
- [x] A Help page linked from every page: the five steps, the words, the colours, and what to do when something stops

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A file added from the page lands only in its engagement's folder, by name, on local storage, for an engagement that is not archived, and the change is recorded with its digest
- A deliverable downloads only if it is inside the delivery folder and matches the digest recorded at release
- A setting in .env reaches a locally started server, and a value in the real environment wins
- Help is linked from every page, its glossary names only words the pages use, and the start script parses
