## Intent

Everything on Activity is indexed by run. An analyst thinks in clients, and a repeat client has several runs behind one engagement. There is no filter, no search and no grouping, so finding Northgate among ten engagements is scrolling. The route that answers the question already exists and no page calls it. Backlog B-026.

- [x] The runs panel can be narrowed to one client, engagement or scope without a page load

- [x] An engagement line says where it stands: scope, run count, what is open, last activity

## Exit criteria
