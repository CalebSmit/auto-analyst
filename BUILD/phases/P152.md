## Intent

Let a CSV and an .xls be read as what they are, by presenting each to the existing workbook reader as a workbook - so sheet selection, normalisation and the Sheet!A1 locators a figure cites all stay exactly as they are.

## Tasks

- [x] a CSV becomes a one-sheet workbook, so the reader above it does not change at all
- [x] an .xls becomes a workbook the same way, through xlrd
- [x] the delimiter, the encoding and the decimal convention are read off the file and carried, and an ambiguous one is not guessed
- [x] the rehearsal's CSV case expects a reading rather than a refusal

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A trial balance sent as a CSV is read, with its figures as figures, and the rehearsal stops counting its refusal as a result
- An .xls is read the same way, and neither format reaches a person as a zip-file error
- A delimiter, an encoding and a decimal convention are decided from the file and reported, and an ambiguous one is reported rather than guessed
