# P103 - The files a run never sees

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** A run that finishes  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-22

## Intent

Let the classifier bind a file the conventions do not claim, so that what P96 can recognise is what a run can read. The firm's own declarations still win, an inference has to be confident to count, and anything neither claims is still held for a person - held is a real state and the point is not to empty it.

## Tasks

- [x] The binder asks the classifier when no convention claims a filename, and binds only on a confident answer
- [x] A convention always wins over an inference, because the firm declaring a token is a decision and a classifier is a guess with evidence
- [x] The record says which of the two bound each file, so an inferred type is visible as one
- [x] A type the Contract Registry does not declare is never bound, whatever the classifier says

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- The thirteen files of the real client folder all enter a run, and the record says which were inferred
- A file neither the conventions nor a confident classification claims is still held
- A filename a convention claims keeps that type even when the classifier would say otherwise
- Nothing binds a document type the registry has not declared
