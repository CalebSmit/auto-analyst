# P151 - A line is not a row

## Intent

Build a statement row from where the words are on the page rather than from how the text stream happens to be chunked, so a total keeps its figures and a number inside a sentence cannot be read as a column.

## Tasks

- [x] pdfplumber is added as a dependency, with what it is for written beside it
- [x] a page's rows are built from word baselines and its columns from where the figures actually sit
- [x] a figure outside the columns stays in the label, which is what stops a share count becoming a balance
- [x] the real filing's balance sheet is checked against what the filing says, total by total

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every grand total on the real filing's balance sheet is built with its figures, measured against the filing rather than against a fixture
- A number that sits in a label rather than in a figure column is never stored as that row's value
- What the reader already got right on that filing it still gets right, row for row
