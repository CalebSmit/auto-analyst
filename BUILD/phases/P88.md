# P88 - A connection test that says which part failed

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Closed.** 2026-09-21

## Intent

Four questions asked in order - are the credentials set, will Box issue a token for the impersonated user, can the folder be listed, can a file's bytes be read - each answered separately. The order is the design: a step after a failure is reported as not reached rather than as failed, because a folder marked failed when the token never issued sends somebody to the wrong setting. It proves the connection now and says nothing about later.

## Tasks

- [x] admin/connection.py: the four steps, in order, stopping at the first failure
- [x] Presence is asked of the Secrets Port so no value is read to test one
- [x] An empty folder is not a broken connection
- [x] A Test button on /admin, and the route behind it

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Each of the four steps reports its own result, and the ones after a failure say they were not reached
- The credentials step never reads a credential's value
- A wrong folder id and a refused token produce different reports
- An empty Box folder reports as connected
- Nothing the test read is written anywhere
