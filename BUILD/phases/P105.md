## Intent

Make the deliverable say what the firm actually wants: figures in thousands, shown to the dollar and stored to the cent. Rounding before the write would bake a rounding error into the number a model is built on, and forty rounded figures do not re-add to the total they came from.

## Tasks

- [x] The input-help workbook declares thousands, and says so on its face
- [x] The value column carries an Excel display format of whole dollars, and the stored value keeps its decimals
- [x] A figure at the wrong scale is still refused by the writer rather than quietly divided

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- The workbook declares scale 1000 and its value cells display no decimals
- A value written with decimals is stored with them, and a test fails if rounding creeps in before the cell
- The writer still refuses a figure whose scale does not match the template's, naming both
