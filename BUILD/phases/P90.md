# P90 - The relay, which may be pressed twice

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** Version one: the buttons he presses

## Intent

Copy from ShareFile to Box and converge rather than compete. Copy and never move, so nothing is deleted from a source the relay might be wrong about. Skip on identical content hash, so pressing it after Power Automate already ran is a no-op that says so. Surface a re-send rather than overwriting it, because a client sending a second version of something is the one case a person has to see. And report per file, because nine of twelve copied is nine of twelve.

## Tasks

- [x] A relay that copies ShareFile to Box, keyed on content hash
- [x] A re-send is reported, not overwritten and not skipped
- [x] Partial failure is named per file rather than retried into silence
- [x] Nothing in a graph step can reach it, and it writes no run record
- [x] The Update button, and what it says it did

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Pressing it twice copies once, and the second press says so
- Nothing is ever deleted from ShareFile
- The same bytes already in Box are skipped; different bytes under the same name are reported as a re-send
- A failure on one file does not stop the others, and every outcome is named
- No path exists from a graph step or a run to the relay
