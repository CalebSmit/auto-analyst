## Intent

A benchmark needs a stable document, so the filing is committed rather than fetched - a test that downloads from sec.gov is a test that fails when the network does, and a document that can move is not a baseline. What the reader does with it runs on every suite, because that is evidence about the reader and needs no engine. What an OCR engine makes of it runs behind a flag, like postgres and redis and the container, because it needs software most machines do not have and saying so is better than skipping quietly.
