# P117 - A workflow a run can finish, and a machine that has one

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** A run that finishes  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-22

## Intent

Stop the dashboard steering a first-time user into a workflow that cannot finish, say which ones can, and make a clean machine able to build its own deliverable - so the money a first run costs buys a workbook.

## Tasks

- [x] Whether a recipe can finish is derived from the procedures that exist, not from a list
- [x] The form offers one that can and says of each one that cannot that it will stop
- [x] Preflight refuses an engagement whose recipe names a skill with no procedure
- [x] A missing template workbook is built by the start path rather than reported to a person who cannot act on it
- [x] Approving a workflow is a step on the checklist, before activation refuses for the want of it

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A first-time user cannot select a workflow that will stop, without being told it will
- A clean machine reaches an activatable engagement without anybody running a build script by hand
- The checklist's steps are the steps, and the count still follows the list
