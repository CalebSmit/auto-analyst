# P11 - LLM port, model pin, budget governor

**Block.** Block C - The harness around one step  
**Gate.** `auto` - closes on green tests alone.

## Intent

One door to a model and one request per step. Per finding F4 this is the Messages API - SKILL.md is a file format we parse, not a framework dependency.

## Blueprint nodes this phase implements

`llm_port` `model_pin` `budget_governor` `payload_scan` `cost_meter` 

## Tasks

- [ ] Anthropic Messages adapter behind the LLM port
- [ ] A SKILL.md parser: frontmatter, body, reference list - our own, owing nothing to any SDK
- [ ] Model pin including effort; the three tiers (claude-haiku-4-5, claude-sonnet-5, claude-opus-5)
- [ ] max_turns == 1 enforced at the call site, not merely asserted in the plan
- [ ] Outbound payload scan on the one door
- [ ] Token and cost meter, and the four budget ceilings

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A call attempting more than one model turn raises before it is sent
- Every outbound payload passes the scan, and the scan's fixture (a stubbed no-op masker) is caught
- Each of the four ceilings halts and escalates in a test
- The cost meter agrees with the usage the API reports

## Verify

```
python -m pytest tests/p11 -q
python tools/gate.py check P11
```

F4 lands here. The Agent SDK's cited benefits - subagent loops, SDK-dispatched tools - are exactly what single-turn removes. It stays available as an adapter behind this port.
