## Intent

One per-engagement setting, stored the way the recipe and the quiet period already are, and checked where the person typing it is still reading. A path that does not resolve is the failure this whole surface keeps producing - registered fine, nothing ever happens - so it is verified at the moment it is entered rather than at the moment a run needs it. It is asked of repeat engagements, because a first-year client has no last year, and a form that demands one would be asking for something that does not exist.

`B-036` 

## Tasks

- [x] An engagement carries where last year's model is, set at registration or afterwards
- [x] The path is checked when it is given, not when a run needs it
- [x] A repeat engagement without one is reported as incomplete; a new client is not asked

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- A repeat engagement can be pointed at last year's workbook and the setting survives a reload
- A path that is not there is refused while the person is still looking at it, naming what was not found
- A new-client engagement is neither asked for one nor faulted for having none
- Older configuration versions stay listed and readable, and a document naming no prior model is not upgraded
