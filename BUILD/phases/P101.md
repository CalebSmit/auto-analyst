# P101 - Version 1's own recipe, ending at a workbook nobody has to trust

*Generated from BUILD/plan.json by `gate render`. Change it with `gate amend`.*

**Block.** A run that finishes  
**Gate.** `auto` - closes on green tests alone.
  
**Closed.** 2026-09-22

## Intent

Give version 1 a path a run can actually complete: intake, masking, timing, tagging and a mapping onto an input-help workbook, built only from skills that have a procedure. The workbook is laid out like the model's inputs and is not the model - he copies from it, so nothing this build writes can be mistaken for the firm's own file.

## Tasks

- [x] A recipe whose every skill step names a skill with a procedure, so no step can quarantine for being a skeleton
- [x] An input-help workbook and its declared inputs, separate from the model template and labelled as not being one
- [x] Bind it at the focus scope so a non-ESOP valuation resolves to it, leaving every other scope as it is
- [x] What the recipe cannot fill is listed as unmapped and shown to a person, rather than left blank or guessed

## Exit criteria

*The phase closes when all of these are true and `gate close` says so.*

- Every skill the recipe names has a procedure, and a test fails if a skeleton is added to it
- The workbook it writes is not the firm's model template, and says so on its face
- An input nothing in version 1 can produce is reported unmapped with its name, not silently skipped
- A released run on the focus scope gets through every step that has a procedure and ends on its own - waiting on a person for the inputs it could not place, rather than stopping at a step nobody built
