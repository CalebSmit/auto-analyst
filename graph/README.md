# graph/

**What belongs here.** The run as data: resolve.py, recipes.py, compile.py, execute.py,
and the two assertion suites. The compiler produces a typed DAG and a plan_hash; nothing
executes uncompiled.

**What does not.** No domain knowledge. The graph does not know what EBITDA is.

## resolve.py - Tier 0

Deterministic Python, no model. A scope path walks five layers and comes back as one set:
the applicable skills, the overlays in force, the template to build into, and the
precedent scope that may be retrieved from.

**Deeper shadows shallower, and only by declaring the same skill.** A layer never removes
what a shallower one gave it, so no run loses a firm skill by being specific.

**An overlay may only tighten.** It may raise a review floor, narrow a privacy class and
take tools away; never the reverse. A loosening raises rather than warns, because a review
floor that was quietly lowered is indistinguishable from one nobody set.

## compile.py - a recipe becomes a plan, or it does not run

An undeclared cycle, a ceiling nobody agreed to, or a step asking for more than one model
turn: all refused while building. `plan_hash` covers structure, skill versions, model
pins, effort, schemas, template, taxonomy, constraints, the scope resolution and the
precedent-store snapshot.

## Two graphs, two suites

Conflating them is the mistake that made three assertions unsatisfiable in the
blueprint's first draft.

| | architecture_assertions.py | plan_assertions.py |
|---|---|---|
| Graph | 118 nodes, one per repo | ~8 typed steps, one per run |
| Source | `architecture.json`, exported from the blueprint | a `CompiledGraph` |
| Runs | in CI, on every commit | inside `compile_recipe`, every compile |
| Answers | is the design intact | is this run legal |

`assert_no_generation_writes_a_verified_figure` is the example worth understanding. On
the architecture graph, "no model step downstream of a guard" is false by construction -
the untrusted boundary and the payload scan are guards and are ancestors of every model
call there is. The plan version is about *writes*, not ancestry: a step running after
verification must have no field in its output contract a figure could enter through.

### Why the assertions walk content edges

The graph draws ten kinds of edge and only three move work: `flow`, `masked`, `guard`. A
`record` edge reports, a `pref` edge configures, a `port` edge binds, a `human` edge is a
person acting. Walk all ten and the Analyst Chat - a read-only surface - "reaches" the
model builder in twenty-five hops, and every dominance claim collapses for reasons that
have nothing to do with the design.

### What a graph cannot prove

Reachability cannot always tell a figure's path from a tool call: a skill reaches the
recompute engine, and the recompute engine reaches the tie-out gate, but no figure
travelled that way. Where that bites, the assertion tests specific edges instead of paths
and its docstring says which half of the invariant is structural and which half a guard
enforces at run time. An assertion that overclaims is worse than one that is narrow and
honest about it.

### The test that makes them mean something

`tests/p07/test_edge_deletion.py` breaks the design in one place at a time and asserts the
**exact set** of invariants that notice - the right one fires, the others stay quiet - and
that all 25 are broken by at least one case. Writing it found three assertions passing
vacuously: remove the edge they were about and the loop they iterated had nothing in it,
so silence read as success. All three now check the thing exists before checking what
guards it.

## Keeping the export honest

`architecture.json` is generated by `tools/export_architecture.py` from
`docs/architecture.html` and checked in. It records a digest of the exact source blocks it
came from, and a test recomputes that digest - so editing the blueprint without
re-exporting fails a test rather than leaving the assertions checking a design nobody has
any more.

    python tools/export_architecture.py            # re-export
    python tools/export_architecture.py --check    # exit 1 if stale
