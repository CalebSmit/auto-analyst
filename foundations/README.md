# foundations/

**What belongs here.** Firm standards every skill must follow: valuation standards, QC
conventions, tagging policy, house rules. Attached to every skill invocation by the
Context Builder rather than referenced per skill.

**What does not.** Anything specific to one skill - that is a reference file under the
skill's own folder. Anything specific to one engagement - that is the engagement profile.

## Why unconditional

Making this a builder-level attachment rather than a per-skill reference means the
standards cannot be omitted by whoever writes the next skill. It is one of the few things
worth making non-optional.

Every file here passes the Untrusted Content Boundary like any other document. Firm-
authored does not mean safe.

## Skeletons

The files here are placeholders with the shape of the real thing, so the Context Builder
assembles against something real and `context_ref` is honest. Their content is written
when the practice group writes it - the system does not invent firm standards.
